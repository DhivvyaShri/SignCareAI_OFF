SIGNCARE AI — TRAINING & MODEL STATUS

1. Continuous ISL Sequence Model:
   - Checkpoint: isl-backend/models/isl_continuous_sequence.joblib
   - Labels: isl-backend/models/continuous_labels.json
   - Classes: CHEST_PAIN, DOCTOR, FEVER, HELP, MEDICINE, NO, PAIN, WATER, YES
   - Feature Representation: 20 temporal frames x 126 normalized dual-hand landmarks
   - Baseline held-out evaluation saved: isl-backend/models/continuous_evaluation.json
   - Re-train on custom clips:
       python isl-backend/train_continuous_model.py

2. RealSign Fingerspelling A-Z Alphabet Model:
   - Script: isl-backend/train_model.py
   - Dataset layout: isl-backend/dataset/Training/A/ ... Z/
   - Download dataset from: https://github.com/RealSign62/RealSign-Indian-Sign-Language-Dataset

3. Dataset Readiness Audit:
   - Script: python isl-backend/prepare_isl_dataset.py --auto-create-folders
   - Report: isl-backend/dataset/dataset_readiness_report.json

Patient confirmation is mandatory for all machine interpretations.
This prototype is designed for healthcare communication support, not clinical diagnosis.
